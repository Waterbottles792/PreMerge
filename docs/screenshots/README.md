# Screenshots

Evidence of the GitHub Flow branching strategy described in the
[main README](../../README.md) §13.

Capture each of these from the GitHub web UI after pushing the feature branch,
save it here with the filename given, and it will render in the table below.

| # | Filename | What to capture | Where to find it |
|---|---|---|---|
| 1 | `01-branches.png` | The branch list showing `main` and `feature/project-documentation` | Repo → **Branches** tab |
| 2 | `02-pull-request.png` | The open PR, title and description visible | Repo → **Pull requests** → the open PR |
| 3 | `03-checks.png` | The PR's checks section — `Tests` and `PreMerge Conflict Risk Check` | Bottom of the PR **Conversation** tab |
| 4 | `04-premerge-comment.png` | PreMerge's own risk-report comment on the PR | PR **Conversation** tab |
| 5 | `05-files-changed.png` | The **Files changed** tab | PR → **Files changed** |
| 6 | `06-merged.png` | The PR after squash-and-merge, showing the merged badge | The PR, after merging |
| 7 | `07-network-graph.png` | The branch topology | Repo → **Insights** → **Network** |
